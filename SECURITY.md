# Security Policy

## Reporting a vulnerability

Report security vulnerabilities privately. Do not open a public issue,
discussion, or pull request for security reports.

Use the
[private vulnerability reporting form](https://github.com/hillmarkets/documenso/security/advisories/new)
for this repository.

If the issue is in code inherited from upstream Documenso (most of the
codebase), please also report it to
[Documenso's security policy](https://github.com/documenso/documenso/security/policy)
so it can be fixed at the source.

## Scope

This repository is a self-hosted fork. There is no hosted service operated
from it, so reports about `documenso.com` or Documenso Cloud belong with
upstream, not here.
